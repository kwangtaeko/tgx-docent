# 1.0 공개 릴리스 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 실제 개인 레포(`kwangtaeko/portfolio`)에 docent를 처음부터 끝까지 적용해 드러난 문제를 고치고, 한/영 README·데모 GIF·라이선스·버전 1.0.0을 갖춰 `kwangtaeko/tgx-docent` 마켓플레이스로 공개한다.

**Architecture:** 실전 적용은 레포 밖(스크래치패드 복사본)에서 SKILL.md 흐름을 그대로 따라 하며, 발견한 문제는 일반화된 테스트로 고친다(개인 레포 내용은 이 레포에 커밋하지 않는다). 데모 자산은 개인 정보가 없는 `fixtures/nextjs-sample`로 만든다.

**Tech Stack:** 기존과 같음(Node.js 20.10+ ESM, `node:test`, esbuild 번들, Playwright 1.56.1). 실전 대상: Next.js 16 + pnpm.

**Spec:** `docs/superpowers/specs/2026-10-13-docent-design.md` (16장 1.0 "실전 적용(개인 레포 몇 개), README(한/영)·데모 GIF, 마켓플레이스 등록", 17장 검증 기준, 19장 열린 항목)

## Global Constraints

- Node.js 20+, ESM(`.mjs`), 테스트 의존성 없음 — `npm test`
- 같은 입력이면 같은 결과가 나와야 하는 일은 스크립트, 해석은 에이전트. 모든 서술은 소스 근거를 가진다
- 비밀 파일은 읽지 않고, 비밀 값은 저장하지 않는다. 동의 없이 설치·실행 명령을 돌리지 않는다
- **`portfolio`의 소스·분석 결과·캡처는 이 레포에 커밋하지 않는다**(개인 정보). 실전 기록에는 일반화된 문제와 수치만 쓴다
- `portfolio` 레포에는 아무것도 커밋·푸시하지 않는다(읽기 전용)
- 배포 위치: `kwangtaeko/tgx-docent` 유지(사용자 결정, 설계 19장 해소). 버전 1.0.0, 태그 `v1.0.0`
- `scripts/src/`나 `schemas/`를 고치면 `npm run build`로 `dist/`를 다시 만들어 함께 커밋한다
- 문서 문체: 한국어 합니다체, 영어 README는 평이한 문장

## Review Focus

1. **pnpm 프로젝트** — run-guide·SKILL이 pnpm(`pnpm install --frozen-lockfile`, `pnpm build && pnpm start`)을 안내하고, `packageManager` 필드가 있으면 그 도구를 쓴다고 적혀 있다. Task 2 실전 점검과 Task 3 문서 테스트.
2. **정적 내보내기·PDF 링크가 많은 사이트** — crawl이 `/pdf/*.pdf`·`/talks/*.html` 같은 정적 파일을 화면으로 세지 않는다. Task 1 테스트 "정적 HTML 파일 링크는 화면 후보가 아니다".
3. **화면 수가 많은 개인 사이트에서 build 결정성** — 같은 `.docent`로 build 두 번이면 HTML·README 바이트가 같다(기존 테스트가 nextjs-sample로 덮음; Task 2에서 실전 결과로 다시 확인).
4. **영어 README의 링크·명령이 한국어 README와 어긋남** — Task 4 테스트 "한/영 README의 명령 블록이 같다".
5. **릴리스 버전 불일치** — plugin.json·marketplace.json·package.json 버전이 모두 1.0.0. Task 5 기존 매니페스트 테스트 확장.
